🛡️ Official Privacy Policy — 100% Local & Zero Data Collection

Last Updated: November 2026
Extension Name: AI Response Audio Scape
Developer: Ojus Wankhede (ojuswankhede@gmail.com)
Single Purpose: Plays a soothing, continuous audio loop strictly while supported AI chatbots are actively thinking or generating a response, and halts playback immediately when generation finishes.

  • Zero Data Collection or Transmission: AI Response Audio Scape does not collect, log, track, harvest, inspect, or transmit any user information, personal data, chat prompts, AI responses, IP addresses, browsing histories, or usage analytics. Zero bytes of data ever leave the user's local device.
  • Zero External Network Calls: The extension makes zero remote API requests, zero tracking calls, zero telemetry pings, and zero dynamic CDN loads. Every script, stylesheet, icon, and audio asset is 100% locally bundled within the extension package.
  • Strict Content Security Policy (CSP): Enforces script-src 'self'; object-src 'self'; style-src 'self'; with zero eval(), zero dynamic code execution (no new Function()), and zero remote script injection.
  • Local On-Device Storage Only: Sound preferences, volume levels, master toggle states, and optional custom user-uploaded audio files are stored exclusively on the user's local machine via chrome.storage.local / browser.storage.local. This data is never synchronized to external servers and is erased permanently when the extension is uninstalled.
  • No Third-Party Sharing: No data is ever sold, leased, shared, or transferred to advertisers, brokers, or third parties.

📋 Technical Permission Justifications

  • Permission: "storage" Required strictly to save the user's soundscape choice, volume preference, and on/off toggle state locally on their machine.
  • Permission: "unlimitedStorage" Required to allow users to store their own optional custom MP3/WAV loop (up to 8 MB) locally via base64 encoding without exceeding browser quota limits.
  • Permission: "tabs" Used solely to open the local onboarding guide (setup.html) in a new tab upon initial installation and broadcast preference changes from the popup to open AI tabs.
  • Host Permissions: Restricted exclusively to supported AI chatbot domains (ChatGPT, Claude, Gemini, Grok, Perplexity, DeepSeek, Copilot, Poe, Mistral) to allow the content script's DOM MutationObserver to monitor response streaming indicators.
